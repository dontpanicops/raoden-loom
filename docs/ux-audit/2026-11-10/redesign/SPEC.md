# Raoden Loom — редизайн «Calm depth + стекло»

Версия спецификации: v3, 2026-11-10, после сверки с кодом (`../spec-vs-code.md`, `../shots-qa.md`). Прав код: в макетах только команды, которые принимает main.
Макеты — холст Claude Design «Raoden Loom — редизайн». Выгрузка: `shots/` (PNG 2×, полный набор, локально) и `preview/` (JPEG для репозитория). Токены — `tokens.css`, справочные стили компонентов — `components-reference.css`.

## 1. Решения

- Направление A «Calm depth» + стекло на плавающем хроме. Карточки холста непрозрачные.
- 4 темы хрома: **Песок** (тёмная, основная), **Залив** (тёмная холодная), **Бумага**, **Иней** (светлые). В коде сейчас `PaletteId = sage | lilac | night`; светлых тем, «следовать системе» и «меньше прозрачности» нет — это новые поля (см. §6).
- Свечение и акцент — только «ждёт вас» (`--status-waiting`). Главная кнопка нейтральная (Песок, Бумага) или синяя (Залив, Иней).
- Статус тройкой: глиф Lucide + цвет + подпись: `circle` свободен, `loader-circle` работает, `bell` ждёт, `circle-pause` пауза, `triangle-alert` упал, `circle-check` готово.
- Inter для UI, JetBrains Mono для кода. Шкала 11/12/13/15/17/20/24/32. Контраст текста и статусов ≥ 4.5:1 во всех темах (проверено расчётом).

## 2. Изменения контракта (UI_CONTRACT)

1. «Flat pastel tiles, restrained shadows» → уровни 0–4, многослойные тени, кромки; blur только на уровнях 3–4.
2. Шапка карточки 44px вместо 54px (терминал, браузер, плагин) и 3.15em (заметка). **44px умножается на `--ui-scale`**, как сейчас 54px.
3. Панель запуска: 3 вкладки вместо 8 + зона действия над вкладками (§4, §5).
4. Полоса пространств — стеклянная плашка под шапкой окна.
5. Размеры карточек не меняются: агент 300×222 (минимум и фиксированный размер в коде), терминал по умолчанию 700×430 (минимум 420×260), браузер 920×620.

## 3. Уровни

| Уровень | Что | Фон | Тень | Blur |
|---|---|---|---|---|
| 0 | холст | `--surface-0` + узор | — | — |
| 1 | регион | тинт 5% | `--elev-1` | — |
| 2 | карточка, плитка | `--surface-2` → `--surface-2-b` | `--elev-2` + кромка | нет |
| 3 | шапка окна, пространства, панель запуска, тосты, мини-карта | `--surface-3` | `--elev-3` | 28px |
| 4 | модалки, меню, палитра, тултип, поповеры | `--surface-4` | `--elev-4` | 40px |

Выбранная карточка — тень уровня 3 + контур `--focus` 1.5px; фокус клавиатуры — кольцо 2px с отступом 3px (`:focus-visible`). «Меньше прозрачности»: уровни 3–4 → `--surface-3-solid / -4-solid`, без анимаций.

## 4. Панель запуска — паузы по коду

Источник текстов: `orchPause_<причина>_what/_why/_do/_button` (i18n.ts). Тон по `PAUSES` (runModel.ts): **Ж** — «Ждёт вас», свечение; **Н** — «Пауза», без свечения. Команды main: pause_after_turn, stop, resume, step, answer, clarify, recover (accept / retry_turn / reset_to_checkpoint), raise_limit, checks.decide (accept / edit), finish.confirm, check.amend, person.decide, plan.decide, permission. «Остановить запуск» (stop) есть в подвале у каждой паузы — в таблице не повторяется. Локальные кнопки без команды main помечены (лок.).

### 4.3 Варианты внутри причин

- **awaiting_checks_decision · none** — «Лид не нашёл команд проверки»: поле команд → «Сохранить команды» (checks.decide edit) или «Продолжить без проверок» (checks.decide accept).
- **sandbox_unavailable · sandbox_unsupported** (не macOS) — «Здесь нет песочницы для проверок», только «Остановить запуск».
- **needs_user_action · mcp_present** — «У {cli} включены MCP-серверы: {names}. Выключите их в своём конфиге {cli}», главная «Продолжить» (resume).
- **needs_user_action · mcp_unchecked** — «Не удалось проверить MCP-серверы {cli}: ход не выполнен», главная «Продолжить» (resume).
- **needs_user_action · push_protected** — «Push в защищённую ветку {name} не выполнен: «Продолжить» не поможет». Главная «Остановить запуск» (stop), вторичная «Настройки проекта» (лок.). Всегда защищены main, master и базовая ветка запуска — в настройках показаны как неснимаемые.
- **permission** (во время хода, не пауза) — «Разрешить один раз / На весь запуск / Отклонить» → permission; вид `kind = plan` — запрос плана (ExitPlanMode).

### 4.4 Не паузы — отказы старта

- **push_not_confirmed** — отказ старта автопилота с push: баннер в настройках автопилота «Не запущен: включение push не подтверждено» + «Подтвердить push…» (окно подтверждения).
- **push_option_field** — причина задачи доски: баннер на карточке задачи «В option поле {field}, которого нет у задачи…» + «Открыть задачу». Автопилот такую задачу не берёт.

### 4.5 Поле «Уточнить» (clarify)

Живёт в зоне действия (свёрнуто кнопкой «Уточнить», раскрывается в поле + «Отправить»). Скрыто при: awaiting_checks_decision, awaiting_finish_confirmation, check_needs_permissions, awaiting_person_decision, coverage_lost, journal_corrupt, запросе плана (permission kind=plan), у завершённых / остановленных запусков и запусков новой версии. При loop_suspected поле раскрыто сразу.

### 4.6 Статусы и общее

- Работает: зона «Работает», в подвале «Пауза после хода» (pause_after_turn) и «Остановить запуск».
- Завершён: «Забрать результат» (TakeResult), «Новая цель»; Итог без противоречий (Н5).
- Упал / остановлен / halted (целостность): причина словами, «Открыть лог»; ничего не продолжается само.
- Отказ команды показывается кодом словами (`orchError_<code>`: stale_revision, invalid_state, invalid_command, unknown_question, confirm_required, not_admitted). Сбой связи — нейтральный баннер «Нет связи с процессом запуска» + «Повторить». До ответа main — «Отправляю…».
- **Несколько запусков связи** (до 4 живых): ряд переключателей с id и точкой статуса над зоной действия; панель показывает выбранный.

## 6. Темы, фон холста, HOME — как ложится на код

- Новые id и классы. Белые списки `PALETTES / CANVAS_COLORS / HOME_ACCENT_PRESETS` (SettingsStore.ts) надо расширить, иначе выбор сбросится.

| Поле | Значение в коде | Новое | Класс |
|---|---|---|---|
| palette | sage / lilac / night | Песок / Залив / Залив; + новые paper, frost | `.app--sand/-bay/-paper/-frost` |
| canvasColor | sage / lilac / night / sand / mist / rose / slate | Камень / Сирень / Ночь / Лён / Туман / Сирень / Ночь; + новый «Графит», «Как в теме» | `.app--canvas-stone/-lilac/-night/-linen/-mist/-graphite` |
| homeAccentPreset | classic / warm / cool / mono / custom | Пастель / Тёплая / Холодная / Моно / Своя; + новые «Нейтральная» (по умолчанию для новых установок) и «Сумерки» | `.app--home-pastel/-warm/-cool/-mono/-dusk`; без класса — нейтральная |

- Миграция (SETTINGS_VERSION 16): canvasColor sage/lilac/night, равный palette, считать «не выбранным отдельно» и брать пару по таблице; иначе — по значению поля. HOME classic → Пастель (не нейтральная).
- Переменные HOME: в коде `--home-launcher-dock / -tile`, в токенах `--home-dock / --home-dock-tile` — алиас или переименование.
- Новые поля: `followSystem`, `reduceTransparency` (и «меньше движения»). Цвета терминала задаются темой (`--term-bg / -fg / -dim`, `--ansi-*` в tokens.css); TerminalCard сейчас берёт их от palette.
- Узоры совпадают с кодом: dots, grid, waves, diagonal, rings, none.

## 7. Экраны (артборды)

- **Холст целиком** — шапка, пространства, HOME, браузер, терминалы, заметка, регион, связь, мини-карта, зум; тема и «Меньше прозрачности» переключаются в Play.
- **HOME** — 1:1, ячейка 82×72, зазор 18; лимиты по данным, «нет данных» словами; поповер упавшей сессии.
- **Первый запуск** — «С чего начать»; агентских CLI 9 (Claude Code, Codex, Qwen Code, Kimi Code, OpenCode, Hermes, Grok Build, OMP, Pi).
- **Карточки** — терминал (показан минимум 420×260), браузер 920×620 (бейдж агента — заглушка марки + имя), агенты 300×222.
- **Панель запуска** — 18 состояний (§4) + вкладки по коду (§5).
- **Доска** — 4 колонки; автопилот: после старта приложения всегда выключен; чип — ожидание (запуск / человек / лимит / внешняя задача) или причина остановки; настройки: бюджет запусков (5) и минут (240), параллельность 1–4 (2), конфликт «Агент / Человек», push с подтверждением.
- **Новая цель, Карточка запуска агента, Настройки проекта** — без изменений к v2.
- **Настройки — 8 разделов**: Общие, Уведомления (баннер, системное уведомление, бейдж Dock), Оформление, Агенты, Управление, Браузер, Плагины, О программе.
- **Пространства** — «Закрыть» = **«Скрыть»**: ничего не останавливает, запуски и терминалы продолжаются и видны в виджете активности. Отдельно «Остановить всё и скрыть» с итогом по каждому запуску и терминалу. Последнее открытое скрыть нельзя. «Удалить» — только пустое пространство без карточек и истории запусков; общий холст удалить нельзя.
- **Окно не на macOS** — свернуть / развернуть (maximize есть) / закрыть, 46×44. На macOS их нет: maximize — зелёный светофор.
- **Связи** — повторная пара запрещена (`link_duplicate`, показывать нейтрально); связь всегда лид → исполнитель; исполнитель левее — коридор между карточками; при 0.2× линия 1.5px и чип-точка.

## 8. Изгиб связи — что добавить в код

`bend?: { along: number; across: number } | null` в `OrchestrationAgentLink`; метод стора `setLinkBend(linkId, bend)` (проверка конечности и диапазона, `null` — сброс, без `busy`); IPC `orchestrationLinkSetBend` + preload + `OrchestrationApi`. Рисование: кубическая кривая, `P1 = P0 + (c,0) + 4/3·bend`, `P2 = P3 − (c,0) + 4/3·bend`, `c = max(80, |dx|/2)` — кривая проходит через `H = M + bend`. Чип и `linkTrace` пересчитать под кривую. `createLink` с тем же `linkId` не должен затирать `bend`.

## 9. Новое поведение, которого нет в коде

Тосты: до 3, успех 4 с, ошибка и «ждёт вас» до действия (в коде один тост на 2.6 с). Контроль контраста своей палитры HOME. Режимы «Лента / Журнал / Записи» как один переключатель. Светлые темы, «следовать системе», «меньше прозрачности».

## 10. Масштаб, строки, честность

- `--ui-scale` 0.85–1.25: хром, панели, меню, диалоги, шапки карточек; не зум холста, не ячейка HOME, не шрифт терминала. Текст не меньше 11px.
- Кнопки не переносятся — ряд уходит в столбец; имена и пути режутся «…», статус никогда.
- Нет выдуманных процентов и счётчиков; действие не показывается выполненным до ответа main.
- Иконки Lucide; марки провайдеров — пунктирные заглушки «лого», файлы подставляются без изменений (Kimi ≤ 48px). Цвета провайдеров — только точкой в бейдже (документировано в «Токены v2»). Над нативным браузером ничего не рисуется. Нет maximize у карточек.
