# Raoden Loom — редизайн «Calm depth + стекло»

Дата: 2026-11-10. Макеты: холст Claude Design «Raoden Loom — редизайн» (13 артбордов). Токены: `tokens.css` рядом.
Справочные стили компонентов из макетов: `components-reference.css` (классы `.rl`, `.t-*` — те же значения, что в токенах).

## Решения

- Направление A «Calm depth» + стекло из B на плавающем хроме. Карточки холста непрозрачные.
- 4 темы: **Песок** (тёмная, основная), **Залив** (тёмная холодная), **Бумага** (светлая тёплая), **Иней** (светлая холодная). «Следовать системе» = Бумага днём / Песок вечером.
- Акцент со свечением — только «ждёт человека» (`--status-waiting`). Главная кнопка нейтральная (Песок, Бумага) или синяя (Залив, Иней).
- Статус всегда тройкой: глиф Lucide + цвет + подпись. Глифы: `circle` свободен, `loader-circle` работает, `bell` ждёт, `circle-pause` пауза, `triangle-alert` упал, `circle-check` готово.
- Шрифт UI — Inter (SF Pro допустим первым в стеке на macOS), код — JetBrains Mono. Шкала 11/12/13/15/17/20/24/32.
- Контраст проверен расчётом: текст и статусы ≥ 4.5:1 на всех поверхностях всех четырёх тем.

## Изменения контракта (UI_CONTRACT)

1. «Flat pastel tiles, restrained shadows» → объёмный язык: уровни 0–4, многослойные тени, кромки; blur только на уровнях 3–4.
2. Шапка карточки — 44px для всех видов (было 54px и 3.15em). Если нужно оставить 54px — меняется только `.hdr` height.
3. Панель запуска: 3 вкладки (Итог · Ход работы · Изменения) вместо 8 + закреплённая зона действия.
4. Полоса пространств — отдельная стеклянная плашка под шапкой окна (шапка 44px, зона светофора 72px слева).

## Уровни

| Уровень | Что | Фон | Тень | Blur |
|---|---|---|---|---|
| 0 | холст | `--surface-0` + узор | — | — |
| 1 | регион | тинт региона 5% | `--elev-1` | — |
| 2 | карточка, плитка | `--surface-2` → `--surface-2-b` | `--elev-2` + кромка | нет |
| 3 | шапка, пространства, панель запуска, тосты, мини-карта | `--surface-3` | `--elev-3` | 28px |
| 4 | модалки, меню, палитра, тултип, поповеры | `--surface-4` | `--elev-4` | 40px |

Выбранная карточка: уровень 3 по тени + кольцо `--focus` 1.5px. Ждущая: кольцо `--status-waiting` + свечение 22px.
«Меньше прозрачности и движения» (`.app--reduce` или системная настройка): уровни 3–4 получают `--surface-3-solid / -4-solid`, анимации выключены.

## Экраны (артборды)

**1 · Холст целиком** — шапка 44 (стекло), полоса пространств с счётчиками (работает: дуга + число; ждёт: колокол в чипе), HOME, браузер, 3 терминала, заметка, регион с лидом и исполнителем, кривая связь со стрелкой, мини-карта, подсказки, зум. Переключатели темы и reduce работают в Play.

**2 · HOME крупно** — 1:1, ячейка 82×72, зазор 18. Лимиты: обратный отсчёт + рельс по данным; «нет данных» словами; жёлтый рельс + строка = устаревший снимок. Сессии: строка 30px, «ждёт ввода» наверху с подсветкой; поповер упавшей сессии (уровень 4) с хвостом вывода и «Скопировать».

**2б · Первый запуск (Н12)** — карточка «С чего начать» (уровень 3, 560px) рядом с HOME: 1) терминал, 2) установить CLI (найдено 0 из 6, одна строка вместо шести «CLI не найден»), 3) связать агентов. Шаги отмечаются по фактам. HOME в пустом состоянии с подписями.

**3–5 · Карточки** — терминал 420×260: свободен, работает (выбрана), ждёт одобрения, вышел (Restart + ⌃D), упал, сводка < 0.5×. Статус — в подвале, не в шапке. Браузер: вкладка 32px с бейджем агента, адрес, полоса загрузки 2px без процентов, скрытая страница = семантическая поверхность. Агент 260×200: свободен с портом, работает с лентой, упал, отказ main на карточке.
Связь: кубическая кривая Безье от порта лида к исполнителю, ручка изгиба в середине у выбранной связи, стрелка на конце, пунктир бежит при «ждёт». Чип связи — уровень 3, всегда с причиной (Н1), ставится у середины кривой со смещением от карточек (Н14).

**6 · Доска** — 4 колонки на утопленном фоне, задачи уровня 2. Автопилот: сегмент Вкл/Выкл + чип состояния (вкл / ждёт / выкл). Внешняя задача — чип источника. Ошибка задачи — баннер внутри карточки + действие. Пустая колонка — подпись. Импорт из inbox — поповер-отчёт (добавлено / пропущено с причиной).

**7 · Панель запуска** — 400px (360–480 по --ui-scale), уровень 3. Зона действия над вкладками, одна главная кнопка с глаголом-результатом. «Остановить» — контурная danger в подвале (Н2). 9 состояний: работа идёт, вопрос, разрешение MCP, план, лимит (текущее значение в подписи поля, Н7), push, спорное ревью (опасное — вторичное контурное ниже разделителя, Н6), завершён (итог без противоречий, Н5), упал (+ отдельный вид «нет связи»). Журнал — блоки по ходам и командам с действием в углу; детализация Подробно/Обычно/Кратко.

**8 · Новая цель** — 640 × до 820, только вертикальный поток (Н8). Требования — строки; команды проверки — моно-поля по одной; подсказка из package.json одной кнопкой; готовность проверяется сразу; блокер выключает «Начать» и называет причину.

**9 · Настройки** — модалка 1040×740, сайдбар 220 на 7 разделов, «О программе» внизу. Оформление: тема (4 карточки), следовать системе, масштаб 0.85–1.25, фон холста, узор, палитра HOME, строки сессий, меньше прозрачности. Агенты: хуки статуса, таблица провайдеров (CLI найден / как установить, в доке, лимиты), быстрый запуск, состав меню «Запустить».

**10–11 · Оверлеи** — контекстное меню + подменю, радиальное меню (6 секторов, подписи всегда), палитра ⌘K (сверху группа «Ждут вас»), баннер «N запусков ждут вас» для событий вне экрана, тосты: успех/инфо 4 с, ошибка и «ждёт вас» — до действия; до 3, снизу справа.

## Масштаб и длинные строки

- `--ui-scale` 0.85–1.25 умножает размеры хрома (шапка, панели, меню, диалоги, тексты). Не влияет на зум холста, ячейку HOME и шрифт терминала (14px).
- Минимальный текст 11px не уменьшается при 0.85.
- Русские строки: кнопки не переносятся — ряд кнопок переходит в столбец; имена сессий и пути режутся «…» с тултипом, статус никогда не режется; подписи полей переносятся.

## Честность данных

Нет процентов без данных, нет фальшивых счётчиков. Действие показывается выполненным только после ответа main; до этого кнопка в состоянии «Отправляю…». Отказ main — баннер danger со словами причины; сбой связи — нейтральный баннер «Нет связи» + «Повторить».

## Ограничения, которые соблюдены

Иконки только Lucide; марки провайдеров в макетах — пунктирные заглушки «лого», подставляются файлы без изменений (Kimi ≤ 48px). Над нативным браузером нет теней, blur и оверлеев. Нет maximize. Настройки — модалка из двух панелей.

- **Связи** — повторная пара запрещена; одна высота → прямая; исполнитель левее → коридор между карточками; 0.2× → линия 1.5px экрана и чип-точка; изгиб = одна точка `bend {along, across}` от середины в осях P0→P3, `P1/P2 += 4/3·bend`, сброс → `bend = null` (авто-кривая).
