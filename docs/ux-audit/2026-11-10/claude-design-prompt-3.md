  (accept / retry_turn / reset_to_checkpoint), raise_limit, checks.decide (accept / edit), finish.confirm, check.amend,

  - provider_limit_at: автопродолжения по времени нет. Время сброса показывается подписью, кнопка «Продолжить».
  - plan_review: «Начать работу по плану», «Один шаг», «Уточнить задачу».
  - loop_suspected: поле «Уточнить» прямо в зоне действия, затем «Дать ещё раунд».

## 2. Вкладки — ничего не потерять

По `spec-vs-code.md` §2:
- **«Итог»**:
  - факты результата: commit, push, QA с хэшами;
  - план по версиям v1…vN и декомпозиция (предложено, отклонено, «делать целиком»);
  - решения по находкам (закрыть / в пожелания);
  - участники (роль, протокол, доступ, модель, «Наблюдать»);
  - время и лимиты, окружение сессии;
  - выгрузка ревью;
  - документ «Результат» (отчёты, созданные файлы, «На холст»).
- **«Ход работы»**: лента событий (сообщения, мысли, инструменты, файлы) и журнал записей с раскрытием деталей строки.
  Фильтр ролей «Лид / Исполнитель / Проверки», индикатор «агент молчит N мин». Детализация «Лента / Журнал / Записи»
  вместо «Подробно / Обычно / Кратко».
- **Запуск более новой версии**: показаны все вкладки, кроме «Изменений». Отдельное состояние «показаны только цель и
  записи» (fallback) и действие «Отпустить связь».
- Над вкладками зона действия: в ней **несколько запусков одной связи** (до 4 живых) и выбор, какой показан.

## 3. Прочее по коду

- **Агент** остаётся 300×222, это минимум в коде. Терминал по умолчанию 700×430, браузер 920×620.
- **Шапка карточки 44px** умножается на `--ui-scale`, как сейчас.
- **Закрытие пространства** — это «Скрыть»: скрытие ничего не останавливает, запуски и терминалы продолжаются и
  остаются в виджете активности. Если человек хочет, есть отдельный выбор «Остановить всё и скрыть» с итогом по каждому
  запуску и терминалу. Последнее открытое пространство скрыть нельзя. «Удалить» доступно только пустому пространству,
  без карточек и без истории запусков. Убери плейсхолдер `[ПОВЕДЕНИЕ main]`.
- **Настроек 8 разделов**: добавь «Уведомления» (баннер, системное уведомление, бейдж Dock).
- **Автопилот**: состояние не переживает перезапуск, после старта приложения он выключен. Чип показывает ожидание
  (запуск, человек, лимит, внешняя задача) или причину остановки. Настройки: бюджет запусков и минут, параллельность
  1–4, конфликт «агент / человек».
- **Первый запуск**: агентских CLI 9, а не 6.
- **Окно не на macOS**: maximize есть. На macOS его роль выполняет зелёный светофор.
- **HOME**: «Как в теме» — новая нейтральная палитра; «Пастель» — бывшая classic.
