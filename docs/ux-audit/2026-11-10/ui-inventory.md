- Прочее из кода: Toast без типов; `Dialog` без focus-trap (только Esc); три вида диалогов (зелёный `launch-dialog`, тёмный `terminal-link-dialog`, `Dialog` оркестрации); два параллельных стиля шапок (54px у терминала/браузера/плагина против 3.15em у агента/доски); панель запуска 420px — узкая для 8 вкладок и длинных форм; разные радиусы карточек (17 vs 14px); `RunPanel.tsx` 2133 строк — основной UX-долг.
- Тест-покрытие текстов: i18n-тест проверяет только наличие строки в обоих языках (`orchestration-renderer-model.test.mjs`).

## 4. Ограничения для дизайна

Жёсткие (UI_CONTRACT.md, EN/RU-зеркало `UI_CONTRACT.ru.md`):
1. Иконки: только локальные SVG Lucide, без новой иконочной библиотеки, без нарисованных SVG в TSX. Марки провайдеров не трогать (ни цвет, ни фильтр, ни размер Kimi >48px). Волны — только `assets/patterns/waves.svg`.
2. Визуальный язык: плоские крупные пастельные плитки, сильный тёмный/светлый контраст, сдержанные тени, без декоративных микроконтролов и пояснительных подписей к очевидному.
3. HOME: ячейки 82×72, зазор 18px, масштаб 1:1 при вмещении, шаги автоподгонки до 0.2x с целыми координатами камеры; состав плиток и поведение (док всегда Terminal+Browser+включённые агенты, Settings нельзя скрыть).
4. Карточки: шапка 54px у терминала/браузера/плагинов; индикатора жизненного цикла в шапке нет; без maximize/fullscreen; мин. терминал 420×260; ниже 0.5x — семантическая сводка, не мелкий xterm; нативный Browser view прячется под диалогами/панелями (любая новая модальная поверхность должна это учитывать).
5. Карточки агентов: фиксированный размер, без ресайза, как заметка; состояние словами; панель запуска справа; при открытом диалоге/панели оркестрации браузер скрыт; id запуска — 8 символов (полный в tooltip); без имён ref-ов контрольных точек; результат не мержится в ветку пользователя.
6. Настройки: двухпанельная модальная (сайдбар с иконками для 7 разделов, About последним), не возвращаться к slide-over с сегментированными вкладками; кнопка закрытия внутри ряда шапки, не перекрывает поля.
7. Размеры хрома следуют `--ui-scale` (0.85–1.25); меню, палитра, радиальный лаунчер, настройки обязаны масштабироваться; масштаб не влияет на зум холста и шрифт терминала.
8. Системные палитры sage/lilac/night; палитра холста и HOME независимы (изменение одной не перекрашивает другую); пользовательские цвета HOME — только `#RRGGBB` с проверкой.
9. Честность данных: нет фейковых счётчиков/процентов/таймеров/детерминированных прогрессов/плейсхолдер-сессий; `needs_approval` только по структурному сигналу адаптера; недоступные данные подписаны, не придуманы; действие не показывается выполненным до ответа main; отказ и сбой транспорта выглядят по-разному.
10. Ввод: ПКМ-диспетчер (пустой холст → регион/заметка/лаунчер/браузер/настройки; терминал/браузер/input сохраняют нативные меню); RMB-hold = радиальное меню; Cmd/Ctrl+K палитра; Home, F2, Mouse3–5; режимы фокуса и захвата колеса; поведение мини-карты. Дизайн не должен ломать жесты (особенно pointer-events оверлеев: `data-interactive`).
11. Проверка после сборки в реальном Electron: Home, Focus Card, Settings, живой терминал, Browser (acceptance checks); smoke `npm run smoke:orchestration-ui`.

Технические:
- Терминал: xterm рисуется собственным рендером, шрифт JetBrains Mono 14px, тема из палитры (`terminalTheme`), размер ячейки влияет на расчёт сетки PTY (Grok запускается только после измеренной сетки); обёртки с transform/zoom холста и мерой мыши (`terminalMouseCoordinates.ts`) трогать осторожно.
- Нативный вид браузера (WebContentsView) лежит поверх DOM: любой оверлей над ним невозможен без его скрытия; тень/скругление/блюр на этом участке не отрисуются.
- Окно macOS: hidden titlebar, светофор слева `{12,10}` — оставить зону ~72px слева в TitleBar (`titlebar__macos-controls-space`), высота 32px; не-mac имеет свои кнопки справа 46px каждая. Vibrancy нет (можно предлагать, но потребует правки main).
- Плагин-виджеты и HOME-плагины живут в sandbox iframe без доступа к токенам хоста: тема для них — отдельный контракт (`docs/plugins.md`, `docs/widget-authoring.md`).
- Локализация: `LocaleId = "ru" | "en"` (`shared/contracts.ts:16`), ключи `Record<keyof typeof ru,string>` — при изменении подписей править оба блока i18n.ts; русские строки длиннее английских (учитывать в кнопках/вкладках/сайдбаре 15.5em); числа в тексте формата `Nд HHч` / `Nd HHh`; плейсхолдеры `{n}`, `{provider}`.
- Доступность (что уже есть): `role=tablist/tab` в панели и пространствах, `role=alert|status`, `aria-live=polite`, `aria-pressed/expanded/haspopup` на меню и доске, 234 `aria-label`, `:focus-visible` с кольцом `--primary`/`--secondary` (inset .12em / 2px), `prefers-reduced-motion`. Чего нет: focus-trap в `Dialog`, светлая тема, high-contrast, токены размеров текста; контраст `--text-muted #747584` на `--surface #353442` низкий (~2.7:1, проверить).
- Дев-ограничения для дизайнера: CSS плоский, глобальные классы БЭМ-стиля (`.orch-*`, `.board-*`, `.agent-card__*`), `contain: layout paint` на плагин-плитках; `app.css` 1476 строк плюс inline-стили в TSX.
